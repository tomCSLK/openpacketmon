These files are only used by the tests (`cargo test`); they are not part of the program or the packages.

Sample data by [IPinfo](https://ipinfo.io), unchanged. Sniffnet added these editions in 2025 (commit `2a0103c05c`,
"fix support for IPinfo's databases"); IPinfo replaces the samples every week, so the files here are older editions.
The metadata of each file names it (`ipinfo … sample.mmdb`).

The PCAP files of the end-to-end tests are generated by the tests themselves (`src/engine/mod.rs`), and the packets of
the dissector and filter tests are written by hand in the test code.
